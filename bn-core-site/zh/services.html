两大支柱，同一片战场：公用事业规模 BESS

BN CORE GROUP 通过两种互补的介入方式，参与电池储能系统的调试与运维（O&M）项目。

01 — 技术现场服务

BESS 工地现场技术介入

我们的技术人员直接在现场介入，按照贵方的程序负责结构化的现场执行工作——检查、机械作业与文档记录，同时与负责项目整体的 EPC、集成商或运营方保持协调配合。这样一来，贵方的工程师与调试专家可以专注于真正需要其专业能力的任务，而我们承担现场工作量，并在需要时将技术异常上报给合适的专家。

介入领域

  • 现场支援：在负责调试的工程师监督下，协助完成 PCS、BMS 与 EMS 系统的检查、接线及功能/性能测试工作。
  • 机械安装与组装：紧固件扭矩检查及通风部件核查。
  • 在冷却系统与变压器部件上采集油样及诊断样本。
  • 运维：预防性与纠正性维护，现场性能监测。
  • BESS 集装箱结构维修：焊接、防腐处理、外壳翻新。
  • BESS 设备到货/接收检验：到货时的外观状态检查、损坏评估及影像记录，在维修或安装之前完成。
  • 现场作业期间的物流与物料搬运支持。
  • 在调试与验收阶段提供技术支持。
  • 严格执行现场安全规程及制造商标准。

关于集装箱维修的具体内容：框架与面板的焊接与校正、外壳的防腐处理与重新喷漆、辅助设备（空调制冷、照明、锁具、出入口）的诊断——当集装箱结构确有需要时，作为同一次现场介入的一部分完成。

纠正性工作的范围：任何纠正或维修工作，仅在与贵方商定的范围内进行，并需贵方对检查中发现的异常情况予以确认后方可执行。BN CORE GROUP 记录技术发现供贵方决策；除明确委托给我们的介入项目外，本公司不对 BESS 装置整体的就绪状态作出保证。

现场介入方法

贵方专家专注于真正需要其专业能力的工作；我们承担现场工作量

1. 到货接收

按照贵方程序，在现场接收到货设备。

2. 检查与记录

依据检查清单进行检验，对每台设备进行外观检查并拍照记录。

3. 报告

您将收到一份清晰的报告：涉及哪些设备、存在哪些异常，并附有相应证据。

4. 决策与整改

由您决定需要整改的内容及执行方。当整改内容属于我们的范围并经您确认后，我们负责执行——您的专家团队则可专注于真正需要其专业能力的任务。

实际案例：单次任务即可涉及在同等数量的设备上安装数十个部件、在每台设备上采集并记录技术样本，并最终提交一份经签署的报告——而客户团队无需为这部分工作派出任何一名工程师到场。

我们派遣的资源

  • 为调试或运维任务派遣合格的技术人员。
  • 根据项目的持续时间与工作量，提供短期或长期支援。
  • 派遣人员纳入客户的组织架构，并接受客户现场监督。
  • 负责派遣工作的行政协调（调动、后勤、合同跟进）。
02 — 技术人员派遣

合格的技术人员，供您的团队调配

BN CORE GROUP 提供的并非一站式服务，而是派遣合格的技术人员与工程师，在贵方监督下加强您自己的团队，共同完成调试或运维项目。

派遣方法

五步法

需求评估

与客户共同分析项目、所需技能及工地背景。

遴选与调动

确定合格技术人员并组织派遣后勤工作。

现场介入

在客户监督下执行任务，严格遵守安全规程。

报告与结项

跟踪任务进展并向客户提交总结报告。

数字化协同

通过我们自有的应用程序跟踪任务：为现场团队提供排班与检查清单，为管理层提供实时监督，并在合同签署后为客户开通安全访问权限。

同时提供

技术审计
